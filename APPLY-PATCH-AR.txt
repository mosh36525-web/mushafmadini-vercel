إصلاح أخطاء Vercel وإضافة آية اليوم

أخطاء forgeApiKey وforgeApiUrl وoAuthServerUrl وappId تعني أن ملفات تكامل Manus/OAuth القديمة بقيت في commit السابق. لا تضف هذه المتغيرات؛ الموقع مستقل عنها. تتضمن الحزمة سكربتًا يحذف فقط الملفات القديمة غير المستخدمة، وإصلاح توافق TypeScript، وبطاقة آية اليوم.

1) فك الأرشيف وانسخ محتوياته إلى E:\mushafmadini-vercel، واختر دمج المجلدات واستبدال الملفات.
2) لا تحذف ولا ترفع إلى GitHub ملف .env أو شهادة aiven-ca.pem أو مجلد .git.
3) افتح PowerShell داخل جذر المشروع ونفّذ السكربت:
   cd E:\mushafmadini-vercel
   powershell -ExecutionPolicy Bypass -File .\scripts\remove-legacy-platform-files.ps1
   السكربت يحذف قائمة محددة من ملفات Manus/OAuth القديمة فقط؛ لا يغيّر متغيرات البيئة ولا جداول Aiven أو سجلات المستخدمين.
4) راجع التغييرات:
   git status --short
   من الطبيعي أن ترى D بجانب الملفات القديمة التي حذفها السكربت. تأكد ألا تظهر .env أو aiven-ca.pem أو node_modules.
5) أضف ملفات التطبيق والملفات القديمة المحذوفة فقط، دون ملفات أسرار الجذر:
   git add -A -- client api server shared drizzle scripts README-DEPLOY-AR.md TODO.md vercel.json
   git status --short
6) ادفع إلى فرع الإنتاج main:
   git commit -m "Remove legacy integrations and fix Vercel checks"
   git push origin main
7) انتظر Vercel → Deployments حتى يظهر commit جديد على main بحالة Ready ويصبح Latest. لا تعِد نشر commit a17f943 القديم.
8) إذا كان لدى Vercel Build Command مخصص في إعدادات لوحة التحكم، اجعله مطابقًا لـ vercel.json:
   pnpm check && if [ "$VERCEL_ENV" = "production" ]; then pnpm db:check && pnpm db:migrate; fi && pnpm build:static

بعدها تحقق أن pnpm check يمر دون أخطاء. سيُبطل ترحيل 0005 رموز الاستعادة القديمة، وستظهر آية اليوم أعلى الرئيسية. لا تحذف جداول أو بيانات Aiven.
