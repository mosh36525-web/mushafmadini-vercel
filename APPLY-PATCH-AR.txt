تحديث مهم: تسجيل الدخول باسم المستخدم وكلمة المرور فقط

1) احفظ نسخة احتياطية من Aiven إذا لم تفعل ذلك.
2) فك أحدث نسخة من هذا الأرشيف.
3) انسخ محتويات الأرشيف إلى جذر المشروع E:\mushafmadini-vercel واختر دمج المجلدات واستبدال الملفات المتكررة.
4) اترك .git وملف .env وشهادة aiven-ca.pem الموجودة في مشروعك كما هي؛ لا ترفعها إلى GitHub.
5) احذف الملفات القديمة إن كانت موجودة:
   server\_core\emailAuth.ts
   server\_core\emailDelivery.ts
   server\emailDelivery.test.ts
   لا تحذف جداول Aiven أو بيانات الحسابات.
6) حزمة التحديث تزيل شاشة ورموز الاستعادة، وتوقف endpoint قبولها. كما تضيف ترحيلًا 0005 يعطّل كل رموز الاستعادة القديمة التي سبق إصدارها؛ جدولها يبقى دون حذف بيانات.
7) افتح PowerShell داخل E:\mushafmadini-vercel ونفّذ:
   git status --short
   git add -A
   git status --short
   راجع القائمة وتأكد أنها لا تحتوي .env أو شهادة أو مفتاحًا.
8) إذا كان فرع Vercel الإنتاجي main، نفّذ:
   git commit -m "Use username and password only for account access"
   git push origin main
   وإلا استبدل main باسم الفرع الصحيح.
9) انتظر أن يصبح نشر Vercel Ready؛ الترحيل 0005 سيبطل الرموز القديمة أثناء النشر.
10) افتح الموقع. إنشاء الحساب يسجل دخولك مباشرة، وعلى جهاز آخر تدخل بالاسم وكلمة المرور نفسيهما.

مهم: لا يمكن استرجاع كلمة مرور منسية باسم المستخدم وحده. من دون بريد أو عامل تحقق بديل، احفظ كلمة مرورك في مكان آمن.
