المشروع الكامل المحدّث — المصحف المديني

هذه نسخة مصدر كاملة من المشروع تتضمن التحديثات الموجودة في النسخة الحالية، إضافةً إلى صفحة اختبارات المراجعة الجديدة.

الطرق الموجودة للتسميع والاختبار:
1) التسميع الذكي/المباشر الموجود سابقًا في جلسة المراجعة؛ نموذج التلاوة محلي في المتصفح، وتبقى صفحة الاختبارات اليدوية مستقلة عنه.
2) المراجعة اليدوية: إخفاء الآية، التسميع من الحفظ، كشف النص، التقييم الذاتي، والتسجيل الاختياري للاستماع إلى صوت المستخدم داخل المتصفح.
3) اختبار تسميع عشوائي: يخلط آيات النطاق، ويُقيّم المستخدم نفسه بعد كشف كل آية.
4) أكمل الآية: تُحذف كلمات عشوائية ويكتب المستخدم المفقود؛ المقارنة محلية، وتتجاهل الحركات والتشكيل وبعض فروق الكتابة مثل صور الألف.
5) اختر الآية التالية: يعرض آية ويختار المستخدم الآية التي تليها من بدائل عشوائية؛ يحتاج النطاق إلى 3 آيات متتابعة على الأقل.

الاختبارات اليدوية لا تستخدم AI ولا ترفع صوتًا أو نصًا. نتائج التقييم الذاتي تُحفظ محليًا على جهاز المستخدم. ويظل مسار /manual-review-test مستثنى من بدء التحميل المسبق للنموذج عندما يُفتح مباشرة.

كيفية استبدال ملفات المصدر بأمان:
1) حمّل ملف ZIP وفك ضغطه فوق مجلد المشروع الحالي. هذا يستبدل الملفات المصدر المطابقة فقط، ولا يتطلب حذف مجلد المشروع.
2) لا تحذف مجلد .git ولا ملف .env المحلي ولا شهادة قاعدة البيانات aiven-ca.pem؛ هذه الملفات غير مضمّنة في الأرشيف ويجب إبقاؤها كما هي.
3) هذا أرشيف مصدر، وليس مجلد نشر. لا يحتوي node_modules أو dist؛ لا تنسخ هذين المجلدين من إصدار قديم.

PowerShell:

$Project = Join-Path $env:USERPROFILE "mushafmadini-vercel-ntfs"
$Zip = Join-Path $env:USERPROFILE "Downloads\mushafmadini-full-updated-with-tests.zip"
Test-Path $Zip

إذا ظهرت True:

Expand-Archive -LiteralPath $Zip -DestinationPath $Project -Force
Set-Location $Project
Test-Path ".\client\src\pages\ManualReviewTests.tsx"
Test-Path ".\client\src\pages\ManualReviewTests.css"

يجب أن تظهر True مرتين. ثم افحص وابنِ المشروع:

pnpm check
pnpm test
pnpm build:static

في نسخة المصدر الحالية: فحص TypeScript نجح، و47 اختبارًا نجحت، وبناء Vite انتهى بعلامة ✓ built. تحذير حجم بعض ملفات JavaScript وتحذير deprecation لا يمنعان نجاح البناء إذا ظهر ✓ built.

بعد نجاح الفحوصات، راجع الملفات التي ستُرفع:

git add -- client package.json pnpm-lock.yaml vitest.config.ts
git status --short
git diff --cached --check
git diff --cached --stat

لا تتابع إذا ظهرت ملفات أسرار أو تغييرات غير مقصودة. إذا كانت التغييرات المطلوبة فقط staged، نفّذ:

git commit -m "Add complete manual Quran review tests"
git push origin main

ثم انتظر نشر Vercel حتى تكون حالته Ready. افتح الموقع، انتقل إلى المراجعة اليدوية، واضغط «اختبر حفظك».
