# نشر المصحف المديني على Vercel

## تجهيز المصدر

فك ملف ZIP إن كان هو طريقة الاستلام، ثم انتقل إلى **المجلد الجذر للمشروع** الذي يحتوي `package.json`:

```bash
cd madiniplus
node --version  # Node.js 22
pnpm --version  # pnpm 10.18
pnpm install --frozen-lockfile
```

ارفع **المصدر كاملًا** عبر Git Import في Vercel أو Vercel CLI من هذا المجلد. لا ترفع مجلد `dist` وحده أو تسحبه كبديل عن مشروع المصدر؛ فالمسارات `/api/*` ووظيفة OAuth تحتاج ملفات الخادم و`api/index.ts`.

## قبل النشر

هذا المشروع يستخدم **Manus OAuth الموجود أصلًا**. لا توجد حسابات بريد/كلمة مرور محلية، ولا ينبغي إضافتها كحل بديل.

أضف في إعدادات بيئة Vercel أسماء المتغيرات الموجودة في [`.env.example`](./.env.example) بالقيم التي يوفرها مشروع Manus وخدمة قاعدة البيانات. لا تضع أي قيمة سرية في الواجهة أو في Git.

| المتغير | الغرض |
|---|---|
| `DATABASE_URL` | اتصال MySQL الخاص بالمشروع؛ يُستخدم على الخادم فقط. عند استخدام قاعدة خارج خدمة Manus المُدارة، يوفّره مالك القاعدة بنفسه. |
| `MANUS_PROJECT_ID` | معرّف عميل OAuth العام. |
| `MANUS_OAUTH_PORTAL_URL` | بوابة التفويض الظاهرة للمتصفح. |
| `MANUS_OAUTH_API_URL` | تبادل الرمز وجلب الهوية على الخادم فقط. |
| `MANUS_JWT_SECRET` | التحقق من جلسة التطبيق؛ سر خادم فقط. |

> وجود الكود وحده لا يمنح بيانات اعتماد OAuth. يجب إعداد الخدمة والبيئة فعلًا، وإضافة نطاق Vercel النهائي (ومسار callback `/api/oauth/callback`) إلى نطاقات إعادة التوجيه المصرّح بها لدى مزود Manus OAuth.

## البناء والمخطط

```bash
pnpm db:generate  # عند تعديل drizzle/schema.ts فقط
pnpm db:migrate   # يطبق migrations الإضافية فقط
pnpm build:static
```

المهاجرة `0001_user_data` إضافية فقط: تنشئ جدول `user_data` المرتبط بمستخدم Manus ولا تلمس جدول المستخدمين أو تحذف بيانات. لا توجد بيانات تجريبية أو مستخدمون وهميون.

لا تضع `db:push` في خط نشر تلقائي لأنه قد يولد تغييرات مخطط غير مراجعة. شغّل `db:migrate` مرة لكل بيئة بعد مراجعة SQL، ثم يتحرر عميل MySQL عند انتهاء أمر Drizzle.

## Vercel

- `vercel.json` يوجّه `/api/*` إلى `api/index.ts` **قبل** fallback الخاص بتطبيق SPA.
- `api/index.ts` يصدّر Express app ولا يستدعي `listen()`؛ خادم التطوير/الإنتاج المستقل فقط هو الذي يبدأ منفذًا.
- المسارات المحفوظة: `/api/oauth/callback` و`/api/trpc/*` و`/api/platform/config.js` و`/api/health`.
- `/api/health` يعرض حالة إعداد آمنة: أسماء المتغيرات المفقودة فقط، وليس قيمها أو أي أسرار.

## التحقق المحلي

```bash
pnpm check
pnpm test
pnpm dev
```

نجاح البناء لا يعني أن تسجيل الدخول أو النشر الخارجي قد تم اختباره. جرّب جلسة Manus حقيقية في نطاق مخوّل بعد إعداد المتغيرات والنطاق المصرّح به لدى OAuth. عند نقص المتغيرات، تعرض صفحة الحساب تحذيرًا واضحًا بدل إنشاء مستخدم محلي بديل.

## الخصوصية والمزامنة

المزامنة تحفظ مفاتيح `madini-` المعتمدة فقط، مع نسخة محلية namespaced لكل مستخدم ونسخة زائر مستقلة. استيراد بيانات الزائر إلى الحساب يحتاج زرًا صريحًا؛ لا تُكتب فوق بيانات الحساب تلقائيًا. تذكيرات المتصفح اختيارية وتعمل أثناء فتح الصفحة فقط؛ لا يوجد ادعاء بإشعارات خلفية.
