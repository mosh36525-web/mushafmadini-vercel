# المصحف المديني

تطبيق عربي متجاوب للقراءة والورد والتلاوة والمراجعة والأدعية والسبحة ومواقيت الصلاة. يحفظ تقدم الزائر على جهازه، ويتيح الحساب اختياريًا مع مزامنة البيانات المحددة عبر MySQL على Aiven.

- دليل Vercel وAiven: [README-DEPLOY-AR.md](README-DEPLOY-AR.md)
- مصادر المحتوى: [CONTENT-SOURCES.md](CONTENT-SOURCES.md)
- إعداد البيئة النموذجي: `.env.example` (لا يحتوي أسرارًا صالحة)

الحساب مستقل بالبريد وكلمة المرور؛ لا يوجد تكامل OAuth خارجي. كلمات المرور تُجزّأ باستخدام scrypt، وجلسة الدخول في كوكي HttpOnly. استعادة كلمة المرور تستخدم رمزًا أحادي الاستخدام صالحًا 30 دقيقة، وتتطلب ضبط Resend API key وعنوان المرسل في إعدادات النشر. من دون نطاق موثّق، يقتصر مرسل Resend التجريبي على بريد مالك حساب Resend. لا يوجد تأكيد بريد عند التسجيل.

أوامر التطوير والفحص: `pnpm dev`، `pnpm check`، `pnpm test`، و`pnpm build:static`. تذكيرات الصفحة تعمل أثناء بقاء التطبيق مفتوحًا فقط.
